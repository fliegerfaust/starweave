# itch.io

**Не запускали и в планах нет.** Исследование 21.10.2026 (PL.5, закрыта): itch.io это витрина и
место для отзывов, а не трафик и деньги. Полный разбор в истории git (`git log -- docs/ITCH.md`).

Если вернёмся, главное:
- **Денег не будет:** выплаты через PayPal или Payoneer, для РФ закрыты. Ставить «No payments».
- **Технически просто:** zip с `index.html` в корне (≤ 1000 файлов, ≤ 500 МБ), относительные
  пути, SDK и модерации контента нет. Нужна сборка `build:itch` с меткой площадки `itch` в
  аналитике (по образцу `build:pikabu`, ~1,5–2 дня вместе с материалами).
- **Кросс-промо разрешено:** ссылки на Telegram и сайт можно оставить. Вызов другу вести на Pages.
- **Аналитика:** кабинет itch удержание не считает; для своей добавить
  `https://html-classic.itch.zone` в `ALLOWED_ORIGINS` сервера (Origin проверить в черновике).
- **Публиковать подготовленными:** дата выхода фиксируется при первой публикации, первая игра
  автора идёт на ручную проверку.
- Обязательная пометка генеративного ИИ (`AI-Generated` / `No AI`), отмечать честно.
- Трафик придётся приводить самим (Reddit, джемы, девлоги).
