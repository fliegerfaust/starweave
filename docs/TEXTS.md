# Тексты обучения на сервере (эпик TX)

Реплики Лебедя в обучении и подсказках первых забегов, пролог пути и окно «Обучение пройдено»
правятся без выпуска игры. Русские правит Денис, английский переводит Claude.

## Где править

https://game.denvalclass.ru/stats/texts, логин и пароль те же, что у сводки (ссылка «Тексты
обучения» есть в шапке сводки).

- Тексты разложены по шагам в том порядке, в каком игрок их встречает.
- Под полем — как реплика выглядит в игре: `*действие*` золотом, `{n}` и `{total}` с примером.
- Сохранить — кнопкой или ⌘+Enter. «По умолчанию» возвращает текст сборки, в истории можно
  вернуть любую прошлую правку.
- Редактор не даст сохранить: пустой текст, другие `{подстановки}`, непарные звёздочки, длинное
  тире, `<` и `>`, слишком длинный текст (реплика до 110 знаков или «свой + 15», подпись
  «свой + 8»; на этих пределах вёрстку проверяет `e2e/texts-long.spec.ts`).
- Кнопки («Далее», «Пропустить», «Понятно», «В путь», «Заново») не правятся: это не голос
  Лебедя, они остаются как в сборке.

## Когда игроки увидят правку

Игра спрашивает тексты при запуске, параллельно со шрифтами, и ждёт не дольше 1,5 с. Успел ответ —
новые тексты сразу; не успел — ответ сохраняется на устройстве и работает со следующего запуска.
Без сети и при сбое сервера — тексты с прошлого раза или из сборки. Сервер кэширует ответ на
минуту. Правка, которая не прошла проверку в игре (`src/i18n/texts.ts`), молча заменяется своим
текстом.

## Перевод (Claude)

Правка русского помечает английский «Нужен перевод» (вкладка English в редакторе).

```bash
STATS_PASSWORD=… npm run texts:pull               # texts/translate.json: ключ → ru, en
STATS_PASSWORD=… npm run texts:push -- texts/en.json   # { "ключ": "English" }, автор claude
```

Если английский остался верным, его отмечают кнопкой «Перевод верен».

## К релизу

`STATS_PASSWORD=… npm run texts:fold` переносит правки сервера в `src/i18n/ru.ts` и `en.ts`:
тексты Дениса становятся текстами по умолчанию сборки. Списки (звенья «Обучение пройдено»)
скрипт тоже переносит; что не нашёл — перечисляет. Потом `npm test` и коммит.

Пароль сводки: `ssh denval grep STATS_PASSWORD /opt/starweave/.env`.
