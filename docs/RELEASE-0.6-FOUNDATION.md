# Ревью архитектуры перед 0.8 «Глубина» — итог

Ревью 21.10.2026 (~20 тыс. строк): расширяемость, гибкость, безопасность. Витрина —
[d8-arch](vitrines/d8-arch.html). В тот же день всё найденное закрыто, кроме списка «Открыто»
ниже. Подробности — в коммитах с номером задачи. Как код устроен теперь — [ARCHITECTURE](ARCHITECTURE.md).

## Что нашли и что сделали

| Область | Было | Стало |
|---|---|---|
| Сохранения | без миграций, чужая версия стирала забег и профиль | цепочка миграций, сейчас v4, тест на сохранение 0.5.9 (TD.1, в проде с 0.5.10) |
| Глава | «ровно 3 ночи» в ядре и UI | план главы в ядре `core/route.ts`, карта только рисует (TD.6) |
| Ход ночи | один монолит `placeCard` | этапы: выкладка → `onPlaced` → формации → подсчёт → политика клеток → добор (TD.3) |
| Полнота | забытая фаза или событие проходили молча | `assertNever` в роутере, презентере, экране ночи (TD.2) |
| Глифы | `switch` в подсчёте | реестр черт карты `content/traits.ts` (TD.4) |
| Источники эффектов | только Знамения и Затмение, зашиты | реестр `EFFECT_SOURCES` (TD.5) |
| Выборы | у пакета свой механизм | очередь `run.pending` и одна сцена «Выбери одно» (TD.7) |
| Прогресс и пулы | профиль писали 9 мест, лавка брала весь контент | `meta/progress.ts`, снимок открытий `run.unlocks` (TD.8) |
| Журнал | нет | `apply(run, cmd)`, `replay(log)` — основа рейтингов 0.7 (TD.9) |
| God-objects | `app.ts` 718, `scene.ts` 1204 строки | Router, RunController, Monetization; board-view, input, forecast (TD.11) |
| Производительность | кэши без предела, замеры каждый кадр | LRU спрайтов, diff HUD, кэш подписей, 30 кадров в покое (TD.14) |
| i18n | ключи строкой | типизированные ключи, тест `{переменных}` (TD.15) |
| Сервер | заливка диска, нет бэкапа, общая сеть | SEC.1–SEC.7, в проде с 0.5.10 |

Страховка рефакторинга: эталон `tests/night-golden.test.ts` — 22 забега бота на всех небах,
хэш событий и итога записан до правок и совпадает после каждой.
