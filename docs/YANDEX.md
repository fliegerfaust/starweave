# Выход на Яндекс Игры — пошагово

Что уже готово в коде: SDK (`src/platform/yandex.ts`) — загрузка, `LoadingAPI.ready`,
`GameplayAPI` start/stop, реклама за награду и межстраничная, облачные сохранения игрока,
язык из окружения, пауза звука на рекламе и при скрытой вкладке, **покупки** (`getPayments`:
цены, купленное, оплата; постоянные товары не «потребляются»). Сборка для портала без
service worker, манифеста PWA, карт исходников; без подсказок «на весь экран» и «на экран
Домой» (они только для своего сайта). Контекстное меню и выделение текста отключены.

## 0. До начала (Денис)

1. ✅ Самозанятость оформлена (оператор указан в юр. текстах).
2. Яндекс ID → [консоль разработчика](https://games.yandex.ru/console/) → принять
   соглашение, заполнить реквизиты.
3. В `legal/config.json` — оператор (ФИО самозанятого) и почта для вопросов по данным.
4. (Желательно) счётчик [Метрики](https://metrika.yandex.ru) → его номер.

## 1. Сборка

```bash
VITE_METRIKA_ID=<номер счётчика> npm run build:yandex
```

Без счётчика — просто `npm run build:yandex`. Результат: `release/starweave-yandex.zip`
(~320 КБ). Сборка печатает предупреждение, если в `legal/config.json` остались заглушки.

## 2. Черновик в консоли

1. «Добавить приложение» → тип «Игра» → загрузить архив.
2. Карточка — тексты и файлы из [`store/yandex/listing.md`](../store/yandex/listing.md):
   название, описания ru/en, «Как играть», категории, теги, иконка, обложки, скриншоты.
3. Настройки:
   - языки: русский (основной), английский;
   - ориентация: портретная и альбомная (игра подстраивается под обе);
   - платформы: компьютер, телефон, планшет;
   - облачные сохранения: включить;
   - возраст: 0+.
4. Реклама: включить межстраничную и за вознаграждение (баннеры в игре не используются).
5. Покупки: включить и завести постоянные товары с id `atlas`, `supporter`, `back_comet`,
   `back_aurora`, `sky_aurora`, `sky_ember` (названия и цены — [MONETIZATION.md](MONETIZATION.md)).

## 3. Проверка черновика (на телефоне и компьютере)

Открыть ссылку черновика из консоли:

- [ ] Игра загружается, полоса загрузки Яндекса исчезает, меню на русском.
- [ ] Обучение проходится до конца, первый подсчёт ждёт «Далее».
- [ ] «Второй шанс» при поражении показывает ролик и даёт +3 хода.
- [ ] «Удвоить награду» показывает ролик и удваивает золото.
- [ ] Между главами — межстраничная реклама, звук на ней молчит и возвращается.
- [ ] Меню → «Звёздный атлас»: цены в янах из консоли, покупка атласа открывает архив и
      «Астролябию», после покупки межстраничной рекламы нет, «второй шанс» — без ролика.
- [ ] Свернуть вкладку / переключиться на другое приложение — звук замолкает.
- [ ] Закрыть игру посреди забега, открыть снова (войдя в аккаунт) — забег продолжается.
- [ ] В английском интерфейсе Яндекса игра открывается на английском.
- [ ] Поворот телефона — игра перестраивается, без прокрутки и обрезанных кнопок.
- [ ] Долгое нажатие на кнопку не вызывает меню «Скопировать».

Если что-то не так — `?debug` в адресе игры показывает диагностику.

## 4. Модерация

Отправить на модерацию; обычно несколько рабочих дней. Замечания приходят в консоль —
присылай текст, правлю и пересобираю архив (номер версии растёт, `npm run build:yandex`).

## 5. После выхода

- Мёрдж релиза в `main`, теги версий (Y.4).
- Смотреть в консоли: удержание D1/D7, время сессии, доход с рекламы; в Метрике —
  воронку обучения и где умирают ([ANALYTICS.md](ANALYTICS.md)).
