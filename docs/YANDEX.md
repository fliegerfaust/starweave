# Яндекс Игры

## Статус

**На стопе (D.3 / CG-5, Денис):** Яндекс так и не починил свой сервис,
выложить игру нельзя. Вернуться, когда починят. С 0.5.10 релизы Яндекс не ждут.

Код готов (`src/platform/yandex.ts`): загрузка и `LoadingAPI.ready`, `GameplayAPI` start/stop,
реклама за награду и межстраничная, облачные сохранения, язык из окружения, пауза звука на
рекламе и при скрытой вкладке, покупки через `getPayments` (постоянные товары не потребляются).
Переключатели CQ (`src/platform/features.ts`) в этой сборке выключены: при выходе решить,
включать ли их, как на остальных площадках.

## Сборка

```bash
VITE_METRIKA_ID=<номер счётчика> npm run build:yandex
```

Без Метрики просто `npm run build:yandex` → `release/starweave-yandex.zip`. Сборка без service
worker, манифеста PWA и карт исходников, без подсказок «на весь экран» и «на экран Домой»;
контекстное меню и выделение текста отключены. Предупреждает, если в `legal/config.json`
остались заглушки. Каждая новая загрузка в консоль с новым номером версии.

## Шаги в консоли (Денис)

1. Яндекс ID → [консоль](https://games.yandex.ru/console/) → соглашение, реквизиты
   (самозанятость оформлена). По желанию счётчик [Метрики](https://metrika.yandex.ru).
2. «Добавить приложение» → «Игра» → загрузить архив.
3. Карточка из `store/yandex/listing.md` (название, описания ru/en, «Как играть», категории,
   теги; картинки `npm run store-assets`).
4. Настройки: языки ru (основной) и en; ориентация обе; ПК, телефон, планшет; облачные
   сохранения вкл.; 0+. Реклама: межстраничная и за вознаграждение, без баннеров.
5. Покупки (AT.9): постоянные товары `atlas`, `supporter`, `back_comet`, `back_aurora`,
   `sky_aurora`, `sky_ember`, цены в [MONETIZATION.md](MONETIZATION.md).
6. Проверить черновик на телефоне и ПК, затем модерация (несколько рабочих дней). Замечания
   присылать Claude: правка и новый архив.

## Проверка черновика

- [ ] Загрузка: полоса Яндекса исчезает, интерфейс на языке Яндекса (ru и en).
- [ ] «Второй шанс» и «Удвоить награду» показывают ролик и дают награду.
- [ ] Межстраничная между главами, звук на ней молчит и возвращается.
- [ ] Атлас: цены в янах из консоли; после покупки нет межстраничной, «второй шанс» без ролика.
- [ ] Свернуть вкладку: звук молчит. Закрыть посреди забега и открыть (в аккаунте): забег на месте.
- [ ] Поворот телефона без прокрутки и обрезанных кнопок; долгое нажатие не вызывает меню.
- [ ] Диагностика: `?debug` в адресе.

После выхода смотреть в консоли D1/D7, время сессии и доход с рекламы
([ANALYTICS.md](ANALYTICS.md)).
