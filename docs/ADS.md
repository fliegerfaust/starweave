## 2. Куда ставим рекламу (и куда — никогда)

Принцип: реклама — это **выбор игрока за награду**, а не плата за вход.

1. **«Второй шанс: +3 хода»** — после поражения в ночи. Самое ценное место: игрок сам хочет
   досмотреть. Готово в коде.
2. **«Удвоить награду»** — на итогах пройденной ночи, вторая кнопка рядом с «Забрать».
   Готово в коде.
3. **Межстраничная** — только между главами (раз в три ночи), только на Яндексе сейчас.
   В Telegram включаем позже и с ограничениями: не в первый день игрока, не чаще раза в
   10 минут, никогда после второго шанса — решение по данным rewarded (AD.4).

**Никогда:** посреди хода, в обучении, на главной при запуске, баннером поверх игры, после
покупки атласа (атлас убирает межстраничную и даёт второй шанс без ролика).

Ориентир дохода: 1–2 просмотра rewarded на активного игрока в день. Регулярный игрок
проходит 3–9 ночей за вечер → 1 второй шанс + 2–4 удвоения.

## 3. Подключить AdsGram в Telegram — что делает Денис

1. Зайти на https://partner.adsgram.ai и войти через Telegram.
2. **Платформы → Добавить**: тип — Mini App, ссылка — `https://t.me/starweave_game_bot/play`,
   категория — Games. Дождаться модерации (обычно 1–3 дня).
3. **Блоки → Создать**: тип **Reward** (видео за награду), имя `rewarded`. Открыть блок →
   «Show code» → скопировать **Block ID** (число).
4. Позже, для AD.4 — второй блок типа **Interstitial** (ID начинается с `int-`).
5. Кошелёк для выплат: в разделе выплат указать адрес TON-кошелька (USDT в сети TON).
   Минимум к выводу — по условиям кабинета (на 2026 год AdsGram писал о $100).
6. Прислать мне Block ID. Он не секретный — я положу его в переменную репозитория:

   ```bash
   gh variable set ADSGRAM_BLOCK_ID --body "<id>"
   ```

Дальше я (AD.1–AD.3): скрипт AdsGram в Telegram-сборке, `showRewarded()` через
`Adsgram.init({ blockId }).show()`, кнопки появляются сами, когда блок задан; звук глушится на
время ролика; события `ad_request` / `ad_result` уже пишутся.

## 4. Где смотреть

### Покупки за Telegram Stars
- **Мгновенно:** бот присылает тебе каждую оплату в чат (`TG_ADMIN_CHAT_ID`).
- **Сводка в боте:** написать боту `/sales`.
- **Сводка на сайте:** https://game.denvalclass.ru/stats → блок «Покупки» (по предметам,
  возвраты учтены). Пароль: `ssh denval cat /opt/starweave/.env`.
- **Деньги:** @BotFather → бот → Monetization / Balance. Stars можно вывести через
  Fragment в TON через 21 день после покупки, от 1000 ⭐ на балансе.
- Возврат: `/refund <id> <charge_id>` боту.

### Реклама
- **Наша сводка** (https://game.denvalclass.ru/stats → «Реклама»): сколько раз игроки
  нажали рекламу и сколько досмотрели, по местам (`revive`, `double_reward`). Денег здесь нет —
  игра их не знает.
- **Деньги и показы AdsGram:** https://partner.adsgram.ai → Статистика: показы, CPM, доход
  по дням и блокам; там же выплаты.
- **Яндекс Игры:** консоль https://games.yandex.ru/console → игра → «Статистика» (игроки,
  показы рекламы, доход) и «Финансы» (начисления и выплаты, покупки).

### Как сверять раз в неделю
1. Наша сводка: досмотры rewarded / активные игроки за день → цель 1–2.
2. Кабинет сети: доход / досмотры → сколько стоит один досмотр (eCPM / 1000).
3. Если досмотров мало — кнопка не на виду; если много, а удержание D1 упало — реклама
   мешает, режем межстраничную первой.
