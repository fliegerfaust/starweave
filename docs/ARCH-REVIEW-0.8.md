# Ревью архитектуры перед 0.8 «Глубина»

21.10.2026. Сеньорская проверка кода (~20 тыс. строк): расширяемость игровых систем, гибкость,
безопасность. Только чтение, правок нет. Витрина — [d8-arch](vitrines/d8-arch.html).

## Вывод

Фундамент здоровый. 0.8 ляжет на него без переписывания, но **не на текущую форму забега и
сохранений**. Перед эпиками A–C нужен эпик «Фундамент» (~3 недели). Часть находок — защита
сервера и сохранения — стоит выпустить в прод сразу, не дожидаясь 0.8: релиз 0.8 может не выйти,
а риски есть уже сейчас.

| Область | Оценка | Коротко |
|---|---|---|
| Ядро правил | 4,5 / 5 | детерминизм без `Math.random`, команды → события, хуки Знамений |
| Контент | 4 / 5 | новое Знамение — один объект; нет пулов по открытиям, реестры на `Record` |
| Поток забега | 2,5 / 5 | «3 ночи на главу» зашито в ядре и UI — развилкам мешает |
| Сохранения и профиль | 2 / 5 | нет миграций: забег и профиль другой версии **обнуляются** |
| Игра и интерфейс | 3 / 5 | роутер один, но `app.ts` и `scene.ts` — god-objects, профиль пишется из UI |
| Безопасность | 4 / 5 | оплата, SQL, XSS, секреты — чисто; диск, сеть и бэкапы на VPS — нет |
| Тесты | 3,5 / 5 | ядро и e2e широко; миграций, профиля и презентера нет |
| Производительность | 3,5 / 5 | кэши без вытеснения, перерасчёт подписей каждый кадр |

## Что хорошо и сохраняем

- **Ядро чистое.** `src/core` без DOM, i18n, времени и случайности. Состояние ГПСЧ лежит в
  `RunState`, поэтому забег воспроизводим, а сим гоняет тысячи забегов.
- **Логика мгновенна, вид — проигрыватель событий.** `placeCard` возвращает `GameEvent[]`,
  презентер их анимирует. Прогноз на небе проигрывает настоящий `placeCard` на копии
  (`game/night/preview.ts:16`), правила не дублируются.
- **Хуки эффектов** (`core/effects.ts`): Знамения и Затмения объявляют только нужные хуки,
  шаги подсчёта пишутся в `ScoreStep` для анимации. Правила собираются по слоям
  (`core/rules.ts`). Сетка обобщена на любой размер и диагонали.
- **Один роутер экранов** — `App.route()` (`game/app.ts:259`); UI не меняет `RunState`
  напрямую, только через команды.
- **Сервер без зависимостей** (`node:http`, `node:sqlite`), оплата Stars идемпотентна по
  `charge_id`, выдача — только по подписанному вебхуку, контейнер `read_only`, `cap_drop ALL`.

## Что мешает 0.8

### Блокеры
1. **Сохранения и профиль без миграций.** `core/save.ts:13`: при другой версии забег молча
   пропадает; новые поля (`route`, `gift`) у старых сохранений — `undefined`.
   `meta/profile.ts:73`: профиль не версии 1 заменяется пустым и затем перезаписывается — профиль
   из облака от новой сборки на старой **стирается**. Полей не проверяют (`seenOmens: null` роняет игру).
2. **Глава = ровно 3 ночи.** `nightIndex` 0..2 и `NIGHT_KINDS[nightIndex]` в `core/night.ts:91`,
   `>= 3` в `core/run.ts:101`, `bosses[ante-1]`; в UI — `ui/screens/map.ts:54,145`,
   `common.ts:35`, `shop.ts:122`. Карта главы сама строит план ночей и повторяет поправки
   щедрой ночи из ядра (`map.ts:62-72`). Развилкам нужен план главы в ядре.
3. **Ход ночи — монолит.** `placeCard` (`core/night.ts:129-185`) в одном теле кладёт карту, ищет
   линии, считает, гасит клетки и добирает. Нет места для «тело сработало при выкладке»
   (Метеор), «карта остаётся после вспышки» (Полярная), «фигура мифа» до линий.
4. **Нет проверки полноты фаз и событий.** `route()` без `default`; `presenter.ts:55-92` —
   забытое событие тихо не покажется. Сохранение с новой фазой на старом клиенте вешает экран.

### Важно
5. **Глифы — `switch` в подсчёте** (`core/scoring.ts:98`). Для тел нужен реестр черт карты
   с хуками — тот же механизм, что у Знамений.
6. **Источники эффектов зашиты:** `activeEffects` знает только Знамения и Затмение
   (`core/scoring.ts:18`). Трофеи, покровитель, пророчества — новые источники.
7. **Выборы разрознены.** Пакет — свой `openPack`, награда — фаза `reward`. 0.8 добавляет пять
   новых «выбери одно» (дар, трофей, Знамение Яркой ночи, Комета, пророчество).
8. **Профиль пишется из 9 мест `App` и из UI** (`app.ts:306…579`, `ui/screens/night.ts:161`).
   Открытия (небосвод) там размажутся, бот и сим их не увидят.
9. **Пулы контента без открытий:** лавка берёт весь `OMEN_LIST` (`core/shop.ts:14`). Набор
   открытий должен попадать в `RunState` снимком — иначе забег перестанет быть воспроизводимым,
   а вызов дня — одинаковым для всех.
10. **God-objects.** `app.ts` (718 строк): движок, покупки, навигация, забег, облако, обучение,
    настройки. `scene.ts` (1204): раскладка, рисование, ввод, доступность, прогноз. `scene.ts:1000`
    сам решает, какая клетка закроет линию, — повтор правила ядра.
11. **Журнала команд нет.** Для рейтингов 0.7 нужен `apply(run, cmd)` с записью
    `{seed, sky, stake, version, cmds}`. Дешевле ввести сейчас, до новых команд 0.8.

### Безопасность
- **Высоко — заливка диска через `/v1/events`.** Лимит на один IP (`server/src/main.ts:57`), с
  ротацией IPv6 из /64 и подделкой `Origin` скрипт пишет гигабайты в сутки; размер базы не
  ограничен (`db.ts`). Диск VPS общий — ляжет и соседняя платформа. Та же ротация раздувает
  `Map` ведер до OOM.
- **Средне — нет бэкапа SQLite:** потеря диска = потеря таблицы покупок.
- **Средне — общая docker-сеть с платформой** (`deploy/docker-compose.yml:50`): из взломанного
  контейнера игры видны БД платформы.
- **Низко:** `SKIES[id]` пропускает ключи прототипа (`challenge.ts:51`, `skies.ts:75`) — ссылка
  `c_1_constructor_…` роняет окно вызова; `?promo`/`?icon`/`?gallery` и `window.starweave` в
  проде; образ `node:24-alpine` и Actions без закрепления; нет CSP у игры.
- **Проверено, чисто:** подпись initData (HMAC, срок), секрет вебхука, оплата без подделки,
  возвраты, SQL, XSS в дашборде, CORS, секреты в git и сборке, `?fakepay` только в DEV.
- **Проверить на сервере:** нет ли `trusted_proxies` в Caddy платформы — иначе
  `X-Forwarded-For` подделывается и лимит обходится без IPv6.

### Производительность (телефон)
Кэш карт без вытеснения (`art/card.ts:62`), `measureText` и перенос подписей прогноза каждый
кадр (`scene.ts:385`), HUD пересобирает Знамения после каждого хода (`hud.ts:171`), прогноз
клонирует весь забег на каждую пару «карта × клетка», RAF 60 кадров и в меню.
