# Продвижение

Задачи: эпики GR, NF, PK в трекере CG. Разборы Threads и Steam Next Fest лежат в ветке
`feature/promotion-research` (`docs/THREADS.md`, `docs/STEAM-NEXTFEST.md`).

**Главное.** Дешевле всего рост даёт сама игра: вызовы друзьям, каталоги, площадки с готовой
аудиторией. Платный трафик только после того, как удержание станет приличным.

## Короткие видео

YouTube Shorts и VK Клипы (TikTok не публикует с российских IP, Instagram заблокирован),
Telegram-канал как склад. Формат 9:16, 7–20 с, в первом кадре уже игра, награда видна без звука,
конец перетекает в начало. Ритм 3 ролика в неделю; оценивать досмотр и D1 по меткам
`src_shorts` / `src_vk`.

`npm run clips` → `store/clips/<ролик>-<язык>.mp4` (1080×1920, 60 fps, в git не хранятся):
`cross` (одна карта, две линии), `puzzle` и `answer` («куда положить девятку?»), `cascade`
(4 · 5 · 6 · 7), `surge` (с нуля до 30 000 за четыре хода). Ключи: `npm run clips -- cross`,
`--lang ru`, `--raw`, `--reuse`.

Игра пишется в Chrome без окна на виртуальном времени (`scripts/clips/virtual-time.js`),
оформление Remotion в `clips/` (`cd clips && npm run dev`), тексты крючков в
`clips/src/Root.tsx`, расклады в `src/dev/demo.ts`. Нужны ffmpeg, Chrome и `npm i` в `clips/`.
