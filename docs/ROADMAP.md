## Деньги из РФ и юрлицо
| Площадка | Выплаты | Что нужно |
|---|---|---|
| Telegram (Stars) | ✅ Fragment → TON | ничего |
| Яндекс Игры | работают | самозанятость (есть), ИП или ООО |
| RuStore | работают | для платежей — **ИП или ООО** |
| Google Play | приостановлены для российских счетов | зарубежное юрлицо и счёт или издатель |

Условия меняются — перед регистрацией сверить с первоисточниками.

## Площадки по шагам
**Яндекс Игры (~1 неделя):** консоль → реквизиты → `VITE_METRIKA_ID=<номер> npm run build:yandex`
→ архив в черновик → облачные сохранения, языки → проверка рекламы, звука, сохранений на
телефоне → товары (AT.9) → модерация. Подробно — [YANDEX.md](YANDEX.md).

**RuStore (2–3 недели):** ИП → Capacitor-сборка → Yandex Mobile Ads и RuStore Billing →
консоль и договор → AAB, карточка, политика → модерация.

**Google Play (3–5 недель):** юрлицо для денег (без него — бесплатная версия) → $25 → для
личного аккаунта закрытый тест **12 человек × 14 дней** → Capacitor, Play App Signing →
AdMob или Yandex Mobile Ads, Billing через RevenueCat → карточка, Data safety, IARC.

**App Store (3–4 недели):** юрлицо и $99/год → Xcode, Capacitor iOS → реклама с запросом ATT,
StoreKit через RevenueCat → карточка (скриншоты 6,9" и 6,5", иконка 1024) → TestFlight → ревью.

## Бэкенд (0.7)
Сейчас — маленький сервер (Node 24 + SQLite, [server/README.md](../server/README.md)): события,
сводка, счета Stars, бот. Дальше — Node + TypeScript с тем же ядром игры, PostgreSQL, Redis на
Timeweb:
1. Аккаунты и сохранения между площадками (гость по умолчанию).
2. Рейтинги вызова дня и бесконечного режима: сервер прогоняет журнал ходов тем же ядром —
   подделать счёт нельзя.
3. Проверка покупок всех площадок, удалённая настройка баланса и A/B-тесты.
4. Живые события: недельный вызов, сезоны.
