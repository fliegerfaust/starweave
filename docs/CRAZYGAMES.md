# Выход на CrazyGames — исследование и пошаговый план

Исследование от 21.10.2026 (PL.1). Источники проверены в этот день — список в конце.
Образец пошагового документа — [YANDEX.md](YANDEX.md), деньги — [MONETIZATION.md](MONETIZATION.md),
реклама — [ADS.md](ADS.md).

**Главное.** Технически игра почти готова: лёгкая HTML5-сборка (~0,7 МБ, 42 файла), ru/en,
портрет и ландшафт, слой площадок. Выход в два шага: **Basic Launch** без денег (7–21 день,
ограниченная аудитория, решают метрики) → **Full Launch** с рекламой SDK. Главный риск — **не
технический, а выплаты**: CrazyGames платит через Tipalti (wire / PayPal), а Tipalti, по
сообщениям других площадок, не платит на российские счета, PayPal в РФ не работает. Basic Launch
бесплатен и рисков не несёт — это хороший тест игры на западной аудитории; деньги — открытый вопрос.

## 1. Требования

### Технические
| Требование | Значение | У нас |
|---|---|---|
| Размер сборки | ≤ 250 МБ, ≤ 1500 файлов | ✅ ~0,7 МБ, 42 файла (`dist-yandex`) |
| Первая загрузка | ≤ 50 МБ; для мобильной главной ≤ 20 МБ; до игры ≤ 20 с | ✅ |
| Пути | только относительные | ✅ `base: './'` в Vite |
| Браузеры | Chrome и Edge обязательно; плохо в Safari — игру там выключат; ChromeOS с 4 ГБ | проверить Safari/iOS |
| Управление | мышь + клавиатура, тач — если есть мобильная версия | ✅ |
| Ориентация | ПК — играбельно в ландшафте; портрет допустим с полями/фоном по бокам; ориентации задаются при загрузке, поворот просит сайт | ✅ игра подстраивается |
| Читаемость | текст читаем при DPR 1 в окнах 907×510, 1216×684, 1280×720, 1920×1080, мобильный 800×450, планшет 1080×607 | ⚠️ прогнать `e2e/fit-audit.js` на этих размерах |
| Мобильные | `user-select: none` на body; работа в приложении CrazyGames (полный экран, safe area); iOS-звук: `resume()` в жесте | ✅ всё есть (`styles.css`, `engine/audio.ts`) |
| Полный экран | **свои кнопки «на весь экран» запрещены** — сайт даёт свой | ✅ настройка показывается только при `platform.id === 'web'` |
| SDK v3, Basic | (необязательно) событие `gameplayStart` | — |
| SDK v3, Full | `gameplayStart/Stop`, Data module для сохранений, `loadingStart/Stop` (необяз.), User module — если есть аккаунты | адаптер (§5) |
| Согласие | если собираем данные помимо SDK — уведомление о политике (не блокирующее окно) | ⚠️ у нас события на свой сервер → ссылка на `/legal/` |

### Контент и запреты
- **Английский обязателен**, язык — из `systemInfo.locale`, иначе английский. ✅ ru/en.
- **PEGI 12**, аудитория 13+. ✅
- **Без кросс-промо**: нельзя ссылки на другие площадки и игры. Можно: политика и соглашение,
  ссылки на сообщество (не на играбельную веб-версию), Steam/Epic для ПК. **Ссылки на сторы — никогда.**
  ⚠️ Кнопка «Открыть в Telegram» в атласе (`atlas.ts`, `VITE_TG_APP_LINK`) — **убрать**.
- **Только реклама через SDK** — AdsGram и любые свои сети запрещены (и лишают выплат по договору).
- **Свои покупки** — только через Xsolla, по приглашению, только вошедшим игрокам; в приложениях
  CrazyGames (iOS/Android) — скрывать. Stars — нет.
- **Свой логин запрещён**: гость должен играть; вход только «через CrazyGames», не главным действием.
- **Новичок — сразу в игру**, максимум 1 клик. ✅ на первом запуске главная кнопка — обучение.
- Оригинальность названия и ассетов; при блокировщике рекламы игра обязана работать.

### Реклама
- **Midgame** — только в естественных паузах (между уровнями, после поражения), не на кнопках
  меню/магазина; на время ролика — пауза и блок интерфейса до `adFinished`/`adError`; звук глушить
  на `adStarted`. Частоту держит SDK: **не чаще раза в 3 минуты** (включая rewarded), ранний
  запрос просто игнорируется (`adCooldown`).
- **Rewarded** — редкая возможность, не обязательная часть; кнопка с иконкой видео, не на экране
  активной игры; «пропустить» того же размера и вида; без цепочек роликов; при `adError` — без
  награды; «за жизнь» — **не на каждой смерти**. Между уровнями — либо midgame, либо rewarded
  «играть дальше», не оба.
- На **Basic Launch реклама выключена** (`adsDisabledBasicLaunch`), игра должна работать и без неё;
  нерабочие кнопки rewarded оставлять нельзя.
- Сверка с нашими правилами ([ADS.md](ADS.md)): «второй шанс» — раз за забег ✅, «удвоить
  награду» на итогах ✅, межстраничная — между главами, первый день нет ✅. Проверить: не
  показываем ли midgame и «второй шанс» в одной паузе.

## 2. Процесс

1. Аккаунт на [developer.crazygames.com](https://developer.crazygames.com) (физлицо можно,
   ограничений по стране в FAQ нет: «no location restrictions»).
2. **Preview** («Submit a game») — загрузить файлы, проверить в их окружении, QA-инструмент ведёт
   по шагам.
3. **QA** — игру играют люди, сверяют с требованиями. Срок первичной проверки не публикуется;
   обновления — обычно в тот же рабочий день, на Basic Launch — сразу.
4. **Basic Launch** — ограниченная аудитория, монетизации нет. Длится ≥ 7 дней и ≥ 500 игр
   (что дольше), иначе закрывается через 21 день.
5. Решение по метрикам (сравнивают с другими играми):

   | Метрика | Ориентир CrazyGames | Головоломки в среднем (их гайд) |
   |---|---|---|
   | Среднее время сессии | 10+ мин у успешных | ~21 мин |
   | D1 удержание | 10–15 % у сильных | 6,2 % |
   | Конверсия (играли ≥ 1 мин) | 80 %+ у лучших | 68 % |

   Все в норме → полная интеграция и заявка на **Full Launch**. Часть → можно доработать и
   повторить Basic. Большинство ниже → игру не пускают; повтор только новой игрой со
   значительными изменениями. **Попытка, по сути, одна — выходить готовыми.**
6. **Full Launch** — глобальный релиз, реклама и выплаты.

Договор — Maxflow BV (Бельгия), право Бельгии, суд Антверпена. Срок — с переходом в Full
Launch, далее продление на год. CrazyGames вправе использовать игру в промо без согласования.

## 3. Монетизация и выплаты

| Что | Как |
|---|---|
| Реклама | midgame + rewarded через SDK (баннеры — по желанию; в головоломках — меню и итоги) |
| Доля | в документации и договоре **процента нет**: «compensation» считается по трафику и рекламе. Сторонние гайды ссылаются на условия джема 2026: **60 % рекламы / 70 % покупок** разработчику — не подтверждено |
| Эксклюзив | не обязателен. По желанию: **+50 % на 2 месяца** после Full Launch, если игра только на CrazyGames среди браузерных порталов и хостится у них. Steam/сторы не считаются; Telegram и свой сайт — уточнять |
| Покупки | Xsolla, **только по приглашению**, только вошедшим; в их мобильных приложениях скрыть |
| Порог и срок | от **€100**, ежемесячно, договор — NET 30–60, цель — до 10-го числа; меньше €100 переносится |
| Способы | Tipalti: wire, ACH, eCheck, **PayPal** — по стране получателя |
| Налоги | Tipalti сам подбирает форму (вероятно, W-8BEN для нерезидента США); выплаты «без учёта удержаний», каждый платит свои налоги; самовыставляемые счета (self-billing) |
| Невостребованное | через 18 мес. уведомление, через 24 мес. — **сгорает** (есть исключение «правовые ограничения», на усмотрение CrazyGames) |

### Деньги из России — риски (честно)
- **Tipalti и РФ.** Официального заявления не нашёл, но Creative Market и PublishDrive (обе на
  Tipalti) пишут: выплаты на российские счета не проходят из-за санкций. Ожидать того же.
- **PayPal** в РФ не работает с 2022 г. Совет CrazyGames «поставить страну США» — только для
  тех, кто реально там; указывать чужую страну или чужие реквизиты — нарушение KYC и путь к
  блокировке и потере денег.
- **Payoneer** в списке способов CrazyGames нет; Tipalti, по тем же источникам, Payoneer в РФ не платит.
- **Зарубежный счёт на себя** (Казахстан, Армения, Киргизия, Грузия и т. п.) — единственный
  реалистичный честный путь, но: Tipalti может проверять гражданство/резидентство, а не только
  банк; открыть счёт нерезиденту — отдельная задача; нужен валютный контроль и уведомление ФНС о
  зарубежном счёте.
- **«Держать выплаты»** — можно копить счета в кабинете (hold), пока способ не появится; через
  24 месяца — риск сгорания.
- **Налоги в РФ.** НПД с иностранной организацией — ставка 6 %, но вид дохода — **лицензия на
  игру** (self-billing — «передача прав»), и допустим ли он на НПД — **проверить с бухгалтером**.
  Договор России с Бельгией об избежании двойного налогообложения частично приостановлен РФ в
  2023 г. — возможно удержание в Бельгии. Не проверено.
- **Вывод:** Basic Launch — без денег, риска нет. Перед Full Launch — написать в поддержку
  CrazyGames и прямо спросить про получателя из РФ; без ясного ответа рассчитывать на ноль.

## 4. Аудитория и перспективы

- **Масштаб:** 50+ млн игроков в месяц (их же цифра в документации), сайт в топ-500 мира.
- **Кто:** в основном англоязычные страны первого эшелона (США, Великобритания); много
  школьников и студентов — 13+, ~33 % трафика 18–24 (Similarweb в пересказе), Chromebook.
  Долю мобильных CrazyGames не публикует; есть приложения iOS/Android (1 млн+ установок в Google Play).
- **Жанр:** головоломки — **крупнейшая категория в топ-100 по заработку**. Карточный раздел
  занят пасьянсами, UNO, «червами». Ближайший аналог — **Pocketro** (покерный рогалик в духе
  Balatro, Unity, май 2025): рейтинг ~8,9 при ~870 голосах — ниша есть, но небольшая.
- **Наши сильные стороны:** правило за 10 секунд, короткие ночи, вызов дня (хорош для D1),
  мгновенная загрузка, не нужен аккаунт.
- **Слабые:** игра думающая и местами текстовая — для школьной аудитории порог выше, чем у
  пасьянса; конверсия «≥ 1 мин» и D1 ≥ 10 % — неочевидны. Наши D1/D7 в Telegram ещё не
  подтверждены (W.1).
- **Деньги — грубая оценка, не данные.** Допущения: 1000 игр/день, ~3 показа рекламы на игру,
  eCPM $2–5, доля 60 % → $4–9 в день, **$100–270 в месяц**. При 100 играх в день — ниже порога €100.
  Хиты портала набирают сотни миллионов игр, но это исключения. Реально ждать: Basic Launch даст
  честные метрики на западной аудитории; доход — только если пройдём в Full и попадём в
  рекомендации.

## 5. Что сделать в коде (Claude)

Сам адаптер — по образцу `src/platform/yandex.ts`. Игра знает только интерфейс `Platform`.

| Что | Как |
|---|---|
| `Platform.id` | добавить `'crazygames'` в тип (`types.ts`) и в аналитику (`initAnalytics`) |
| Выбор площадки | `createPlatform()`: `VITE_PLATFORM === 'crazygames'` → `CrazyGamesPlatform` |
| SDK | грузить `https://sdk.crazygames.com/crazygames-sdk-v3.js`, `await SDK.init()` на заставке; `environment === 'disabled'` → работать как веб (как Яндекс вне портала) |
| Загрузка | `game.loadingStart()` в `init`, `loadingStop()` в `ready()` |
| Игра / пауза | `gameplayStart/Stop` — те же места, что у Яндекса; не дёргать при сворачивании вкладки |
| Реклама | `ad.requestAd('midgame' | 'rewarded', { adStarted, adFinished, adError })` вместо AdsGram; награда — только на `adFinished`; пауза через `onPauseChange` |
| Basic Launch | отдельный флаг сборки `VITE_CG_ADS=0` → `rewardedAvailable = interstitialAvailable = false` (кнопки рекламы скрыты); плюс на `adsDisabledBasicLaunch` выключать рекламу до перезапуска |
| Частота | свою `ad-pacing.ts` оставить (она строже: 10 мин, не в первый день); SDK ещё и сам режет до 1/3 мин |
| Звук | `game.settings.muteAudio` + `addSettingsChangeListener` → общий mute игры, сильнее настроек |
| Язык | `user.systemInfo.locale` → `ru` для ru/be/kk/uk/uz, иначе `en` |
| Сохранения | `data.getItem/setItem` (как localStorage, лимит 1 МБ, дебаунс SDK) для ключей run/profile/settings; включить «Progress Save» в форме загрузки |
| Покупки | `payments = null` (Xsolla — по приглашению и с непонятными выплатами) |
| Атлас | убрать кнопку «Открыть в Telegram» на этой площадке; что показывать вместо покупки — открытый вопрос (§7) |
| Вызов другу | `share()`/`startParam()` через `game.inviteLink({ startapp })` и `game.getInviteParam('startapp')` — ссылка ведёт на страницу игры на CrazyGames, а не на Pages |
| Fullscreen и «на экран Домой» | уже только для `web` — ничего не делать |
| Прогресс | (по желанию) `reportGameCompletedPercentage` по главам; `happytime()` на победу над последним Затмением |
| Сборка | `build:crazygames` по образцу `build:yandex`: `VITE_PLATFORM=crazygames vite build --outDir dist-crazygames`, `strip-web-only.mjs`, zip в `release/starweave-crazygames.zip` |
| Политика | ненавязчивая ссылка на `/legal/` (события на свой сервер) — проверить, что уже видна в меню |
| Проверки | юнит-тест адаптера с поддельным SDK; `e2e/fit-audit.js` на 907×510, 800×450, 1080×607, 1280×720, 1920×1080 при DPR 1; проверка в Preview на ПК и iOS/Android; `?useLocalSdk=true` на localhost |

**Оценка:** адаптер и сборка — 1 день; атлас, вызов, правка вёрстки под окна 16:9 — 1 день;
материалы (обложки, видео 16:9 и 2:3 через `store-assets` и `clips`) — 1 день; проверка в
Preview и правки по QA — 1–2 дня. **Итого ~4–5 дней.**

## 6. Чек-лист

### Денис
- [ ] Аккаунт на [developer.crazygames.com](https://developer.crazygames.com), принять условия разработчика.
- [ ] Написать в поддержку ([developer.crazygames.com/support](https://developer.crazygames.com/support)):
      можно ли получать выплаты гражданину и резиденту РФ, каким способом; можно ли игре
      одновременно жить в Telegram и на своём сайте при эксклюзиве.
- [ ] Решить по атласу и эксклюзиву (§7).
- [ ] Billing (Account → Billing, шаги 1–4 в Tipalti) — **только после ответа поддержки**, без чужих реквизитов.
- [ ] Утвердить материалы витрины, которые соберу:
  - обложки: **1920×1080 (16:9), 800×1200 (2:3), 800×800 (1:1)** — единый стиль, из текста
    только название, без рамок, логотипов, «New/Play»;
  - видео: **15–20 с, ≤ 50 МБ, без звука, 1080p в 16:9 и 2:3**, первый кадр — обложка, без
    чёрных экранов, курсора, ускорения и призывов;
  - тексты en (ru по желанию): описание, «как играть», управление, теги/категории (Card, Puzzle).
- [ ] Загрузить zip в Preview, пройти QA-инструмент, отправить на Basic Launch.
- [ ] Через 7–21 день прислать метрики из кабинета (время, D1, конверсия).

## 7. Вывод

**Стоит — как бесплатный тест на западной аудитории**, с открытым вопросом денег.

| Плюсы | Минусы |
|---|---|
| 50+ млн игроков, англоязычный Tier-1 | выплаты в РФ, вероятно, не проходят (Tipalti, PayPal) |
| Basic Launch бесплатен и ничего не требует от SDK | одна попытка: провал метрик закрывает игру |
| Сборка уже лёгкая, слой площадок готов | аудитория молодая, наш жанр — нишевый |
| Неэксклюзивно, Telegram остаётся | покупки атласа — только Xsolla по приглашению |
| Честные метрики D1 / время сессии без своей рекламы | доля выручки не опубликована |

**Открытые вопросы**
1. Выплаты: что ответит поддержка про РФ? Есть ли у тебя или готов ли ты открыть счёт за рубежом?
2. Атлас на CrazyGames: спрятать магазин целиком, оставить только внешний вид за золото
   или открыть атлас бесплатно (как «полная версия» на портале)?
3. Эксклюзив +50 % на 2 месяца: считается ли наш сайт на Pages и Telegram «другим браузерным
   порталом»? Если да — не берём.
4. Выходить сейчас или после 0.8 «Глубина» и подтверждения D1 в Telegram (W.1), раз попытка одна?
5. Баннеры в меню и на итогах (их рекомендуют для головоломок) — против «спокойных экранов»; по
   умолчанию — без баннеров.
