## Сборка

| Что | Команда |
|---|---|
| Basic Launch, без рекламы | `npm run build:crazygames` → `dist-crazygames/` и `release/starweave-crazygames.zip` |
| Full Launch, с рекламой SDK | `VITE_CG_ADS=1 npm run build:crazygames` |
| Обложки 1920×1080, 800×1200, 800×800 | `node scripts/crazygames-covers.mjs` (арт в `store/crazygames/art/`) |
| Видео 16:9 и 2:3, ~20 с, без звука | `scripts/crazygames-video.mjs` → `store/crazygames/video-*.mp4` |
| Тексты карточки (en) | `store/crazygames/listing.md` |

Адаптер SDK v3 (`src/platform/crazygames.ts`, тест `tests/crazygames.test.ts`): загрузка,
`gameplayStart/Stop`, звук от сайта (`muteAudio`), язык из `systemInfo.locale`, сохранения через
Data module, вызов другу через `inviteLink`. Своей аналитики в сборке нет: метрики даёт кабинет,
окно согласия не нужно. Включить свою: адрес CrazyGames в `ALLOWED_ORIGINS` сервера и ссылка на
политику в игре.

Перед отправкой: `e2e/fit-audit.js` при DPR 1 на 907×510, 1216×684, 1280×720, 1366×768,
1920×1080, 800×450, 1080×607 и в портрете.

## Выкладка в кабинете (Денис)

1. [developer.crazygames.com](https://developer.crazygames.com) → Submit a game. Название
   `Starweave`, HTML5. **Zip портал не принимает:** выделить всё внутри `dist-crazygames/` (⌘A)
   и перетащить. Ориентации landscape и portrait, мобильные да, **Progress Save** (Data module)
   включить, SDK-mute отметить.
2. Preview: ПК (Chrome), Android, iPhone, планшет; пройти QA-инструмент. Красное: скриншот в CG-86.
3. Материалы: 3 обложки, 2 видео, тексты из `listing.md`. Категория Card, дополнительно Puzzle;
   теги card, puzzle, roguelike, deckbuilder, strategy, singleplayer; языки English, Russian; PEGI 12.
4. Отправить на Basic Launch. Он идёт не меньше 7 дней и 500 игр (что дольше), иначе
   закрывается через 21 день. В это время только исправления.
5. Метрики из кабинета в трекер. Ориентиры: время сессии 10+ мин, D1 10%+, сыграли ≥ 1 мин 80%.
   Все в норме → Full Launch со сборкой `VITE_CG_ADS=1`. Провал метрик закрывает игру,
   попытка по сути одна.

## Правила площадки

- **Английский обязателен**, язык из `systemInfo.locale`. PEGI 12, аудитория 13+.
- **Без кросс-промо:** никаких ссылок и упоминаний Telegram, сайта, Яндекса, сторов (ни в игре,
  ни в описании). Можно политику, соглашение, сообщества.
- **Только реклама SDK**, AdsGram и свои сети запрещены. Midgame в естественных паузах (у нас
  между главами), не чаще раза в 3 минуты (держит SDK); на ролике пауза и тишина до
  `adFinished`/`adError`. Rewarded редкий, награда только на `adFinished`, не на каждой смерти;
  между главами либо midgame, либо rewarded, не оба. На Basic Launch рекламы нет, кнопок рекламы
  тоже.
- Свой логин и свои кнопки «на весь экран» запрещены (наши видны только при `platform.id === 'web'`).
- Новичок попадает в игру максимум за 1 клик; с блокировщиком рекламы игра работает.
- Сборка ≤ 250 МБ и 1500 файлов, пути относительные (`base: './'`), Chrome и Edge обязательно,
  плохая работа в Safari выключает игру там.
- Обложки в одном стиле, из текста только название, без рамок, логотипов, «New/Play».
  Видео 15–20 с, ≤ 50 МБ, без звука, 1080p, первый кадр это обложка, без курсора и ускорения.
