# Ролики Starweave (Remotion)

Оформление коротких вертикальных роликов: запись игры в рамке, анимированный крючок шрифтом
игры, конец перетекает в начало. Записи игры кладёт сюда `npm run clips` из корня репозитория
(`public/raw/<ролик>-<язык>.mp4`), он же рендерит готовые ролики в `store/clips/`.

```bash
npm i                       # один раз
npm run dev                 # Remotion Studio: посмотреть и поправить оформление
```

- Тексты крючков и подписей — `src/Root.tsx` (`*слово*` — золотом, `|` — перенос).
- Рамка, анимация текста, повтор — `src/Clip.tsx`.
- Расклады и ходы — `src/dev/demo.ts` в игре; как всё устроено — `docs/PROMOTION.md`.

Remotion бесплатен для частных лиц и компаний до трёх человек
([лицензия](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)).
