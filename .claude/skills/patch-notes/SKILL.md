# Заметки к выпуску

## 1. Какие коммиты

- Версия — из аргумента, иначе из `package.json`.
- Диапазон: от прошлого тега до тега версии (`git tag --sort=-v:refname`). Тега ещё нет —
  до `release/<версия>`, иначе до `HEAD`. Пример: `git log --no-merges --format='%h %s%n%b' v0.7.17..v0.7.18`.
- Задачи: коды из коммитов (`FB.5`, `PH.1`) → `node /Users/Denis/Work/task-tracker/bin/tt.js show <код> --as claude`.
  Заголовок и описание задачи часто объясняют «зачем» лучше коммита.

## 2. Что попадает к игроку

Разбери **каждый** коммит в одну группу:

- **Игроку**: `feat`/`fix`/`perf` в `core`, `ui`, `game`, `meta`, `i18n`, `tutorial`, `art` и любой
  правке, которую игрок увидит или почувствует.
- **Внутреннее — выкинуть**: `docs`, `test`, `ci`, `build`, `chore`, `refactor`, скрипты, аналитика,
  сервер, e2e, витрины, `.claude/`. Сюда же всё, в чём не уверен: лучше пропустить, чем выдумать.
- **Площадка**: правка только под одну площадку (Пикабу, Яндекс, Telegram) — в заметки только для неё.

Скажи, сколько коммитов из скольких вошло. Если игроку ничего — так и напиши, текста не сочиняй.

## 3. Как писать

- Языком игрока, о том, что он видит: не «fix(ui): tooltip button survives blur», а
  «На телефоне кнопка обмена в подсказке Знамения больше не пропадает от касания».
- Термины игры как в интерфейсе (`src/i18n` и `src/ui/keywords.ts`): Знамение, Затмение, Обсерватория,
  созвездие, крест, миф, Резонанс. Английские — из en-словаря, не свой перевод.
- Надписи кнопок сверяй со словарём (`grep` по `src/i18n/ru.ts` и `en.ts`): коммит пишут по-английски
  и называют кнопку по-своему. Так, «Trade» из коммита FB.5 в русской игре — «Отдать».
- Числа баланса — было → стало. Шансы в процентах.
- Без длинных тире, без восторгов и «мы рады сообщить». Коротко, по делу, дружелюбно.
- Не обещай того, чего нет в коде, и не упоминай будущие фичи, если Денис не просил.

## 4. Формат

```
## Звёздное плетение <версия>

**Новое**
- …
**Изменения**
- …
**Исправления**
- …
```

Пустые разделы убрать. С `--short` — 3–5 строк одним списком (для Telegram-канала и поста).
Сразу ниже — тот же текст по-английски (`## Starweave <version>`, New / Changes / Fixes).

## 5. Куда

- В ответ: русский и английский блоки, готовые к копированию.
- Сохранить в `docs/patch-notes/<версия>.md`, если Денис попросит или если файл версии уже есть.
- Публикацию на площадках (Пикабу, Яндекс, Telegram) делает Денис; сам ничего не отправляй.
