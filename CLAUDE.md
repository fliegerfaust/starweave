# Starweave — правила работы

- Общение и документация — по-русски. Идентификаторы кода — как есть.
- **Сообщения коммитов — всегда на английском**, по Conventional Commits 1.0.0:
  `feat(core): …`, `fix(ui): …`, `docs: …`. Номер задачи из `TASKS.md` — в scope или тело.
- Ветки: `release/<версия>` → `epic/<имя>` → `feature/<имя>`; фича мёржится в эпик, эпик —
  в релиз, релиз — в `main` с тегом после выхода. Мёрджи `--no-ff`. Имена веток смысловые.
- Перед мёрджем: `npm run typecheck && npm test`; для вёрстки — `npm run e2e`.
- В `TASKS.md` коротко отмечать сделанное, подробности — в сообщении коммита.
- Деплой: пуш в `main` или `release/**` публикует сборку на GitHub Pages
  (`.github/workflows/pages.yml`).
